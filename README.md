# Caleb Kritzar Portfolio

A multi-page personal portfolio built with HTML, CSS, and JavaScript for GitHub Pages.

## Pages

- Home
- About
- Projects
- Skills
- Contact

## Publish with GitHub Pages

1. Upload all files and folders to the `calebkritzar.github.io` repository.
2. Open **Settings > Pages**.
3. Select **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save and visit `https://calebkritzar.github.io`.
